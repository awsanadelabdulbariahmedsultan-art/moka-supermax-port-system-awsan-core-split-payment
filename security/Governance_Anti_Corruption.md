# ميثاق الحوكمة الرقمية ومكافحة الفساد للشركة القابضة والمنطقة الحرة

## أولاً: نظام الفصل البرمجي المقفل للايرادات (The Automated Split System)
1. **التحصيل الموحد:** يتم تحصيل كافة الرسوم، العوائد الجمركية، والخدمات اللوجستية رقمياً عبر نظام ذكي مركزي يمنع التحصيل النقدي أو اليدوي نهائياً في جميع مرافق الميناء والمنطقة الحرة.
2. **التقسيم الآلي اللحظي:** فور دخول أي مبلغ للنظام، تقوم الخوارزمية البرمجية بفصل الإيراد فوراً وبشكل تلقائي:
    * **60%** تذهب مباشرة لحساب النفقات التشغيلية والشركاء (AWSAN DEW PORT HOLDING).
    * **40%** تُحول عبر سويفت دولي مباشر إلى الحساب السيابي المقفل لـ "صندوق تعز للتنمية TDF" في البنك المركزي.

## ثانياً: شروط حظر الصرف والرقابة الثنائية المشفرة
* **مادة (1):** لا توجد أي صلاحية لأي قيادة تنفذية أو حكومية لإصدار أوامر صرف يدوية أو ورقية.
* **مادة (2):** يدمج النظام البرمجي مفتاح الموافقة النهائي بالهوية الرقمية والرقم الوطني للمهندس أوسان عادل عبدالباري أحمد سلطان (ID: 01010305468). يتم توثيق الصرف عبر محفظة إلكترونية مشفرة تعرض كافة حركات التسييل والموافقة بوضوح شفاف، مما يقضي على الرشاوى، الاختلاسات، أو الجبايات العشوائية بنسبة 100%.
